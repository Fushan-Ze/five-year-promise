# 医学生存模拟器：五年之约

五年制医学本科背景的中文像素校园叙事游戏。自定义姓名与性别，经历十个学期，在日常、科研、恋爱、转行与校园异闻间作选择。游戏在当前浏览器保存周目。

**[打开游戏](https://fushan-ze.github.io/five-year-promise/)**

当前版本 **v1.7**，包含 23 种结局、16 首情境配乐和 615 段合成普通话对白。

## 源码与本地运行

下载并解压仓库里的 `five-year-promise-source.zip`。其中包含完整 React + TypeScript 源码、音乐、配音、测试和运行说明。安装 Node.js 22.12 或以上版本后，在解压目录运行：

```sh
npm ci
npm run dev
```

`npm test` 运行测试，`npm run build` 生成静态站点。GitHub Pages 从本仓库中的完整源码包构建。
